Aula 01
O que é um Sistema Operacional?
Um Sistema Operacional (SO) é um software fundamental que atua como intermediário entre o usuário e o computador. Ele gerencia todos os recursos do computador, como processador, memória, disco rígido e periféricos.
Principais funções:
  • Gerenciar arquivos e pastas
  • Controlar periféricos (mouse, teclado, impressora)
  • Executar programas e aplicativos
  • Gerenciar memória e processador
  • Fornecer interface amigável ao usuário
Exemplos de Sistemas Operacionais: Windows (Microsoft), macOS (Apple), Linux (código aberto), Android e iOS (mobile).
Aula 02
Diferença entre Hardware e Software
Muitas vezes esses termos causam confusão, mas eles representam partes completamente diferentes do computador.
Hardware: São as partes físicas do computador que você pode tocar. Exemplos: processador, memória RAM, disco rígido, monitor, teclado, mouse, placa-mãe.
Software: São os programas e instruções que fazem o computador funcionar. Exemplos: Sistema Operacional, navegador web, editor de textos, jogos, aplicativos.
Aula 03
Periféricos de Entrada e Saída
Os periféricos são dispositivos conectados ao computador que complementam suas funções. Eles podem ser de entrada ou saída.
Periféricos de ENTRADA: Enviam informações para o computador. Exemplos: teclado, mouse, scanner, microfone, webcam, controle do videogame.
Periféricos de SAÍDA: Recebem informações do computador e as apresentam ao usuário. Exemplos: monitor, impressora, caixa de som, fone de ouvido.
Aula 04
Componentes Internos: CPU e RAM
Além do processador e memória, existem outros componentes importantes dentro do computador.
CPU (Unidade Central de Processamento): É o "cérebro" do computador. Responsável por processar todas as instruções e executar as operações. Quanto mais potente, mais rápido o computador.
RAM (Memória de Acesso Aleatório): É uma memória temporária e rápida. Armazena dados enquanto você está usando um programa. Quando desliga o computador, tudo na RAM é perdido. Mais RAM = mais programas abertos simultaneamente.
Aula 05
Atalhos de Teclado Essenciais
Os atalhos de teclado ajudam a trabalhar mais rápido no computador. Aqui estão os mais importantes:
Ctrl + C: Copiar (copia o texto/arquivo selecionado para a área de transferência)
Ctrl + V: Colar (cola o que foi copiado)
Ctrl + X: Cortar (copia e remove do local original)
Ctrl + Z: Desfazer (volta a última ação)
Ctrl + S: Salvar (salva o arquivo atual)
Aula 06
Componentes da Placa-Mãe
A placa-mãe é como o "coração" do computador, conectando todos os componentes. Possui vários slots e componentes importantes:
Placa de Vídeo (GPU): Responsável por processar gráficos e imagens. Envia as informações para o monitor. Computadores potentes têm placas de vídeo dedicadas para games e design.
Aula 07
Tipos de Arquivos e Extensões
Um arquivo é um conjunto de dados armazenado no computador. A extensão é a parte final do nome que indica o tipo:
.txt – Arquivo de texto simples
.docx – Documento do Word
.jpg / .png / .gif – Imagens
.mp3 / .wav – Áudio
.mp4 / .avi – Vídeos
.exe – Programa executável
Aula 08
Unidades de Medida de Armazenamento
O armazenamento de dados no computador é medido em unidades. Quanto maior, mais dados podem ser armazenados:
Byte (B) – Menor unidade (1 caractere de texto)
Kilobyte (KB) – 1.024 B (pequenos textos)
Megabyte (MB) – 1.024 KB (fotos simples)
Gigabyte (GB) – 1.024 MB (filmes, programas)
Terabyte (TB) – 1.024 GB (muitos filmes/dados)
